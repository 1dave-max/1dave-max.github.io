Privacy Policy

AinaraClipper · Last updated 28 September 2026

Who this applies to

AinaraClipper is a personal tool used only by its owner to manage their own YouTube channel. It is not offered to other users.

YouTube API Services

AinaraClipper uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • Channel information: the channel's name, read only to confirm the correct channel is connected.
  • Video uploads: videos the owner has approved are uploaded to the owner's own channel, with their title, description, tags, schedule and paid-promotion setting.

No other YouTube data (such as viewing history, subscribers or other people's data) is requested or accessed.

How data is stored and shared

  • The Google sign-in token is stored only on the owner's own computer and is used only to make the requests above.
  • No data is sold, shared with third parties, or sent to any server run by AinaraClipper. There is no such server.
  • No cookies or tracking are used by this website or the tool.

Removing access

Access can be revoked at any time from the Google Account security settings (Third-party apps & services → AinaraClipper → Delete all connections). Deleting the token file from the computer also removes the tool's access.
